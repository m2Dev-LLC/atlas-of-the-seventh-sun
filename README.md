# Atlas of the Seventh Sun

A Unity 6 top-down expedition game inspired by classic age-of-exploration strategy games.

## First playable

- Explore a procedurally generated continent under fog of war.
- Manage provisions, morale, travel time, and terrain costs.
- Discover four landmark settlements and negotiate for gold.
- Find the Seventh City, secure 120 gold, and return to Dawnwatch to win.
- Supports keyboard controls and a WebGL build target.

## Controls

- `WASD` or arrow keys: travel
- `E`: interact with settlements or the port
- `Esc`: pause

## Unity

- Editor: Unity `6000.6.9f1`
- Template: Universal 2D / URP
- Platforms: Desktop and WebGL

Open `Assets/Scenes/Expedition.unity` and enter Play Mode.
