# Twenty-update gameplay pass

1. Procedural expedition codes now identify each generated map.
2. Terrain generation varies from run to run instead of using one fixed noise field.
3. A persistent score rewards travel, discoveries, caches, and efficient victories.
4. Best score persists locally between browser sessions.
5. Scouting (`Q`) reveals a wider area at a provisions cost.
6. Camping (`C`) trades time and provisions for morale.
7. Limited scout and camp charges create route-planning decisions.
8. Random supply caches create positive travel events.
9. The field journal records the latest three expedition milestones.
10. Discovery banners surface major progress immediately.
11. Animated provisions and morale bars replace abrupt HUD changes.
12. The explorer has a subtle breathing animation.
13. Discovery effects expand into moving, shrinking chart sparks.
14. Discoveries play a three-note ascending musical sting.
15. The HUD now shows score, tool charges, terrain cost, and westward bearing.
16. A field guide explains controls, terrain, and the victory condition.
17. The pause screen has clickable Resume, Restart, Guide, Mute, and Shake controls.
18. Mute preference persists locally and has an `M` keyboard shortcut.
19. Screen-shake preference persists locally and has a `K` keyboard shortcut.
20. Web frame pacing now follows the browser via `requestAnimationFrame`.
