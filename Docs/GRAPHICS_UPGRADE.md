# Cartographic graphics upgrade

- Added crisp biome-specific map glyphs for sea, plains, forest, desert, and mountain terrain.
- Added layered tile shadows and inked coastlines for stronger map depth.
- Added animated ocean chart marks.
- Added a layered Dawnwatch harbor emblem.
- Rebuilt settlements with halo, ink silhouette, regional color, and parchment core.
- Rebuilt the explorer as a directional compass marker with shadow and heading changes.
- Added a palette-colored discovery flash and larger moving discovery sparks.
- Added title-screen sun rays, UI text shadows, and subtle screen-edge shading.
- Disabled MSAA, HDR, dynamic resolution, and anisotropic filtering for cleaner procedural pixel edges.

The project remains code-native and follows `Docs/ART_BIBLE.md`; no external art packages were added.
